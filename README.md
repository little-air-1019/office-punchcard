# Office Punchcard

A Chrome extension that reminds you to drink water or go pee and keeps track of your progress on a cute punchcard.

## Features

- Configurable reminder frequency.
- Define skip times (meetings, lunch, etc.) when reminders should not appear.
- Punchcard UI to mark each reminder as done.

## Usage

1. Open Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select the `extension` folder in this repository.
4. Click the extension icon to open the popup and configure your reminder frequency and skip times.

The extension will create notifications outside of the skip times. Click on a punchcard entry to mark it as done.
